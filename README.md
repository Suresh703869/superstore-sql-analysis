# superstore-sql-analysis
SQL analysis of retail sales data using joins, aggregations, and window functions
 SQL analysis of a ~9,800-row retail sales dataset using joins, aggregations, and window functions to answer business questions. ## Key Findings - Top-selling product: Canon imageCLASS 2200 Advanced Copier ($61,599.83) - Top customer by spend: Sean Miller ($25,043.07) - Strongest sales months: September, November, December (holiday seasonality) - Full running total of sales computed month-over-month using a window function
